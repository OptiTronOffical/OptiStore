# Simple Local Python File Server

A lightweight Python script to host files locally and share them with other devices on your home or office network (like phones, tablets, or other PCs).

---

## 📋 Requirements

* **Python 3.x** installed on your computer. (No third-party libraries required!)

---

## 🚀 Quick Start Guide

### 1. Download / Place the Files
1. Create a folder where you want to host files from (e.g., `MyServer`).
2. Save `server.py` inside that folder.
3. Place any files or folders you want to share inside this same directory.

### 2. Run the Server
Open your terminal (Mac/Linux) or Command Prompt/PowerShell (Windows), navigate to the directory, and run:

```bash
python server.py
