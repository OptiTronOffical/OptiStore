Install endpoint

Where packages are sent when you tap install

Use 127.0.0.1 if this page is open on the PS4 itself, or the console's LAN IP (e.g. 192.168.1.42) from another device. Packages are sent to http://<ip>:12800/api/install.

How it works

One page, three tools, zero installs

1
Serve this folder over plain HTTP From the folder that contains this file, run python3 -m http.server 8080 (or any static server) and open http://<your-ip>:8080/. HTTPS will block requests to 127.0.0.1 due to mixed-content rules.
2
Open it on the PS4's browser Navigate to the same address on the console. Use 127.0.0.1 if the server runs on the PS4 itself, or the LAN IP of the machine hosting it.
3
Start Remote Package Installer (RPI) Launch Remote Package Installer on the PS4. It listens on port 12800 and accepts a POST to /api/install with a JSON body.
4
Install in order Base → Update → DLC. Each .pkg is queued separately and the console fetches them in turn.
📁 Catalogs are read from export_with_covers.json (or games.json) for PS4 and ps5-catalog.json for PS5. Drop them next to this file — the page handles missing files gracefully.
