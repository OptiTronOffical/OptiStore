How it works

Three pages, one library

1
Browse here on your PC This page reads export_with_covers.json. Every title expands to show all its packages — base, updates, DLCs — with size, region, and host info.
2
Open ps4.html or rpi.html on your PS4 In the console's web browser, navigate to the same address but end with ps4.html or rpi.html. ps4.html is the full catalog with a send button on every game. rpi.html is a lightweight sender for pasting any direct .pkg link.
3
Make sure Remote Package Installer (RPI) is running Launch Remote Package Installer on the PS4. It listens on port 12800 and accepts a POST to /api/install with a JSON body.
4
Install in order Base → Update → DLC. Each .pkg is queued separately and the console fetches them in turn.
⚠️ Both pages must be served over plain HTTP for the install to work. HTTPS will block the request to 127.0.0.1 due to mixed-content rules.
