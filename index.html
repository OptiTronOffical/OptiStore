RPI — Remote Package Installer

HTTP API on port 12800

Install Remote Package Installer on the PS4 and launch it before installing. The page POSTs {type, packages} directly to it.
  1. Launch Remote Package Installer on the PS4.
  2. Note the IP (Settings → Network → View Connection Status).
  3. Open the Direct URL tab, paste the IP and a .pkg URL, hit Install.
⚡

GoldHEN Payload — HTTP forwarder

Same packet as the binloader, delivered over HTTP

GoldHEN's binloader listens for raw TCP on 9090, which browsers can't reach. But modern GoldHEN builds also expose an HTTP forwarder on 12800 that relays the same JSON packet internally. The page tries a list of known endpoints in order and shows you exactly what happened in the sender log.
  1. Ensure GoldHEN is loaded on the PS4.
  2. Open the Direct URL tab, pick GoldHEN Payload, hit Install.
  3. Watch the sender log — the successful endpoint is highlighted.

Which links get the Send button

Direct vs. landing page

Send to PS4 appears only when a link ends in .pkg and is not hosted on a known landing-page service (FileKeeper, Linkvertise, FileCrypt, and others). Those show an Open button so you can go fetch the real link. The tag next to each file tells you at a glance which it is.
