How it works

Browse, search, and download

1
Serve this folder over plain HTTP From the folder that contains this file, run python3 -m http.server 8080 (or any static server) and open http://<your-ip>:8080/.
2
Browse the library Use the search bar, region filter, kind chips, and sort options to find what you need. The PS5 Library tab opens a separate page.
3
Open a title Click any card to see its package files. Direct .pkg links download straight from the source; external host links open in a new tab.
4
Install in order Base → Update → DLC. Each .pkg is queued separately on the console. Copy any URL with the 📋 button.
📁 The catalog is read from export_with_covers.json (or games.json). Drop it next to this file — the page handles a missing file gracefully.
