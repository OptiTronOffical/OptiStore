RPI — Remote Package Installer

Runs as a homebrew app on the PS4

The classic approach. Install the Remote Package Installer app on your PS4 and launch it before installing.
  1. Launch Remote Package Installer on the PS4.
  2. Note your console's IP address (Settings → Network).
  3. Enter the IP above and hit Install to PS4.
🐐

GoldHEN — Direct Package Installer

Payload-based, no separate app needed

Load the Direct Package Installer payload through GoldHEN, then send URLs the same way.
  1. Open GoldHEN on the PS4 (via the web browser exploit).
  2. Load the DirectPackageInstaller payload through the payload loader.
  3. Select GoldHEN DPI above and hit install.
🔒

HTTP required for direct installs

Why HTTPS blocks the console

The PS4's installer only speaks plain HTTP. Browsers forbid an HTTPS page from contacting a plain-HTTP device on your local network (mixed-content policy). To use direct install, open this page over http:// instead of https://.
