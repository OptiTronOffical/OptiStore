How it works

⚙️ Background Installation (GoldHEN 2.4b14+)
On the console: Settings → GoldHEN → Debug Settings → Package Installer, then enable Background Installation[reference:5]. Once on, packages you send from this page install in the background — you can keep playing while the console downloads and installs. Note that enabling this disables "Install all", so this tool sends packages one at a time[reference:6].
🧩 Receiver payloads: GoldHEN takes {id, contentUrl, contentName, iconPath} · GoldHEN Background takes {type:"direct", packages:[url]} (the embedded RPI protocol) · RPI takes {type:"direct", packages:[url]} · etaHEN / generic takes {url}.
🔑 Common error codes: 2157510677 already installed · 2157510660 uninstall target missing · 2157510681 task not found · 2157510789 not enough storage · 0x80990033 URL isn't a .pkg or the console couldn't reach the file server
📡 Auto-detect uses two parallel workers to walk 22 common home subnets in 32-address chunks. Your own subnet is probed first. IPs already stored from a previous session are tried before the sweep begins.
📺 On-console mode: if you open this page from the PS4 browser, the user agent is detected and 127.0.0.1 is used automatically — no network scan needed.
💓 Watchdog: once you pick a target, the top bar pings it every 15 s. Green = reachable, red = connection lost.
⌨️ Shortcuts: Enter in URL field → read & add · Ctrl/Cmd + K → focus URL · Ctrl/Cmd + Enter → send all · Esc → clear the URL field.
